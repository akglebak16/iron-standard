# Бойцы из частей

Боец в бою — это набор кадров 152×176: `body`, `weapon`, `portrait`, `headless`, `head`, `flash`,
`corpse`, `corpse_headless`, `bare` (без щита) и `shield`. Рисовать их по отдельности не нужно:
рисуются только **части**, а все кадры собирает скрипт. Образец — пехота Доминиона
(`godot/tools/battle/render_dominion_heraldic.cjs`, `heraldic_source/`).

## Что генерировать (и только это)
1. `torsos.png` — туловища без головы и без щита, с вырезом воротника.
2. `heads.png` — головы с короткой шеей, срез на одной высоте.
3. `shields.png` — щиты целиком, только у щитоносцев.
4. Оружие и кисти (`weapons.png`, `gloves.png`) — только если нужно новое.

**Проверенные промпты и шаблоны для новой фракции — `shareness/skills/unit-parts/PROMPTS.md`** (бери оттуда, меняй только фракцию и клетки).
Конкретные наборы — `heraldic_source/nord-prompts.md` (Нордмарк) и `horses-prompts.md`
(кони и всадники); `parts-prompts.md` — старый способ, правкой `body.png`, больше не использовать.
Генерировать **с нуля по готовому листу того же типа** (торсы по `torsos.png` и т. д., `body.png` —
вторым вложением для масштаба); сборщик сам приводит масштаб, места в клетках не важны. Генератор — OpenAI (ChatGPT/Кодекс): права на
результат у пользователя. Recraft на бесплатном тарифе нельзя (картинки принадлежат Recraft).
Ничего про отрубленное в промптах: модерация режет; кровь и срезы рисует код.

## Как собрать
1. Положи части в `heraldic_source/` (PNG 1254×1254, прозрачный фон, сетка 3×3 в порядке `ids`).
2. Новая фракция: скопируй `render_dominion_heraldic.cjs` и её модуль кожи
   (`dominion_heraldic_art.gd`), поменяй `ids`, `SHIELDS` (где лежит щит: круг `[cx, cy, r]` или
   капля), оружие (`config`).
3. `NODE_PATH=<node_modules с sharp> node godot/tools/battle/render_dominion_heraldic.cjs`,
   затем импорт Godot (`godot --headless --path godot --import`).
4. Правила слоёв, масштабы и проверка — `heraldic_source/assembly-rules.md`. Коротко:
   туловище → голова → передняя половина воротника → щит (так собрана пехота Доминиона; для новых
   бойцов голова кладётся поверх торса без воротника — см. «Правила по опыту»); у `headless` вырез залит кровью;
   у `head` кровью залит низ шеи. Подгонять только числа (`TORSO_WIDTH`, `HEAD_HEIGHT`,
   `NECK_TUCK`, `SHIELDS`), плохую часть — перегенерировать, не латать.

## Проверка
- Тесты: `test_dominion_heraldic`, `test_shield_guard` (без щита + щит = фигура), `test_detached_parts`
  (голова, разрез пополам из своей фигуры, падающий щит), `test_scene`, тесты интерфейса.
- Глазами: `tools/battle/dominion_preview.gd`, `dominion_head_preview.gd`; блок щитом;
  отрубание головы; разрез пополам; найм под знаменем игрока; оба направления.
- `godot/docs/ASSETS.md`: источник частей, генератор, промпты.

## Связанное в бою
- Блок щитом: `OriginalArt.guard_layers` (слои `bare`/`shield`), `UnitView` и native `battle_sprites.cpp`.
- Расчленёнка: только голова (рубящий/дробящий) и разрез пополам (сильный рубящий), рук и ног нет;
  разрубленный роняет щит (`Part.SHIELD`). Кэш картинок — по `get_instance_id()`, не `get_rid()`.

## Правила по опыту (Доминион, 2026-11-18)

Образцы: пехота — `render_dominion_heraldic.cjs`; конница — `render_dominion_cavalry.cjs`,
промпты — `heraldic_source/horses-prompts.md`, `nord-prompts.md`.

### Генерация
1. **Каждую часть генерировать с нуля по готовому листу того же типа**: торсы по `torsos.png`,
   головы по `heads.png`, щиты по `shields.png` (первым вложением), `body.png` — вторым, только для
   масштаба. Не резать на части правкой цельного бюста: так выходили голая шея, стоячий воротник
   и бармица, обрезанная у скул.
2. В промпте прямо прописывать то, что ломалось:
   - торс: вырез **плоский** на уровне плеч, тёмная почти чёрная полость, **никакого стоячего
     воротника** и мехового валика — ничего, что читается как шея;
   - голова: короткая шея-срез под подбородком, **без голой кожи** — её закрывает бармица, борода
     или капюшон до самой линии среза; бармица не обрывается у скул и не расходится пелериной;
     высота головы не больше ~1,3 высоты шлема; плюмаж маленький (не выше половины шлема);
   - щит: целиком, ничего его не перекрывает;
   - всё: прозрачный фон, сетка 3×3, порядок клеток как в таблице бойцов.
3. Кони — **длинные и низкие**, сбоку, видно весь корпус от крупа с хвостом до головы, срез
   ровно по брюху, без ног, седло посередине, **попона тёмная кожаная, не в цветах фракции**.
   Высокий конь «столбиком» с попоной в цветах табарда сливается со всадником.
4. Пользователю: промпты давать текстом, файлы-образцы присылать вложениями и называть порядок
   вложений. Готовые листы пользователь кидает в чат.

### Приём листа (до сборки)
1. Проверить альфу: генератор иногда рисует шахматку вместо прозрачности (RGB без альфы) —
   вычистить заливкой от краёв по светлым малонасыщенным пикселям (контур её останавливает).
2. Пиксели с альфой < 40 обнулить (дымка вокруг фигур ломает bbox).
3. Несколько частей одной картинкой — нормально: резать по пустым столбцам, класть в клетки
   3×3 по центру, ужимать до ~390 px, если не влезает в клетку 418.

### Сборка
1. **Голова лежит поверх торса**, без «сустава» с передней половиной воротника: тот копировал
   поверх бармицы тёмную полость выреза → щель между головой и телом. Сборщик сам находит
   передний край выреза (первый светлый пиксель ниже точки шеи по центру) и опускает голову так,
   чтобы срез заходил на кольчугу на 3 px ниже края.
2. Масштаб головы — **по ширине шлема**, равной пехотному аналогу (замер на 60 % высоты), а не
   по высоте bbox: плюмаж иначе уменьшает шлем.
3. Древковое у конных (решение Глеба, 2026-11-19): **лэнс короткий — 172 px** (206 обрезал наконечник
   верхним краем кадра), хват на 77 % длины; **копьё держат низко на древке — хват на 75 %**, чтобы оно
   поднималось над шлемом. Наконечник всегда целиком в кадре (проверять bbox строки оружия: верх ≥ 5 px).
   Числа зашиты в `render_heraldic_faction.cjs` (`WEAPONS`) и `render_dominion_cavalry.cjs`.
4. Конница: кадр 240×244, якорь (112, 264) как у прежних конных; всадник — пехотный бюст 152×176
   со сдвигом (4, 23); 11-я строка атласа — всадник без коня (разрубленный падает отдельно,
   конь — из ленты `dominion_heraldic_horses.png`).
5. Проверять глазами: рядом с пехотным аналогом в ×2, и область шеи крупно на пурпурном фоне
   (видна любая щель). Старое против нового — тоже показать пользователю до подключения.

### Подключение в локальную копию без Godot
1. Ассеты класть уже импортированными: `.godot/imported/<имя>.png-<md5("res://путь")>.ctex` =
   заголовок `GST2` (как у соседних ctex) + lossless WebP, рядом `.md5` и `<png>.import`
   (копия соседнего без `uid`). Иначе `run-godot.ps1` не запустит импорт и `preload` упадёт.
2. После новых PNG: `node godot/tools/export_asset_paths.cjs`; новые файлы — в
   `godot/docs/architecture/file-inventory.json`; источник — в `godot/docs/ASSETS.md`.
3. Перед правкой копии — сохранить оригиналы в `heraldic_source/_out/backup` (удалять файлы в
   копии нельзя).
