Файла `CHANGELOG.md` больше нет: история версий живёт в [Releases](https://github.com/akglebak16/iron-standard/releases).

1. В описании PR заполни раздел `## Для игрока` (его подставляет `.github/pull_request_template.md`; при `gh pr create --body` впиши его сам). Если для игрока ничего не изменилось, напиши «нет».
2. Пиши по-русски, простыми словами, списком: что изменилось для игрока. Код и детали реализации — в «Что сделано».
3. Если правка работает только в одиночной игре или меняет сохранения, так и напиши.
4. Выпуск версии делает Глеб: Actions → «Выпустить версию» → Run workflow (версию можно не указывать — будет следующая минорная). Workflow соберёт разделы «Для игрока» из всех PR, слитых в `main` после прошлого релиза, и создаст релиз `vX.Y.Z`.
5. Правка уже выпущенного текста — прямо на странице релиза на GitHub.
