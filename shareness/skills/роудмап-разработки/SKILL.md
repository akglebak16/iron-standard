# Роудмап разработки (Notion)

Все задачи по игре живут в Notion, в базе «Роудмап»: [доска «Железный Стяг — разработка»](https://app.notion.com/p/418ab976afd881c4a938f791def016a2). Файлов задач в репозитории нет.

Источник данных для запросов: `collection://418ab976-afd8-81a2-a543-000b62d2cf1f`.

## Главное правило
**Одна ветка = одна карточка в роудмапе.** Ветка без карточки не бывает. Статус карточки двигаем сразу вместе с веткой, а не «потом»: ИИ не заканчивает работу, пока статус не соответствует состоянию ветки.

| Что произошло с веткой | Статус карточки | Что ещё заполнить |
|---|---|---|
| Ветка создана и запушена (или собираешься делать первый коммит) | `в работе` | `Исполнитель` (человек, чей ИИ работает, не сам ИИ), `Ветка` (точное имя ветки) |
| Открыт Pull Request | `на проверке` | `PR` (номер) |
| PR слит в `main` | `готово` | `Готово` (дата слияния) |
| PR закрыт без слияния или ветка брошена | `можно брать` (или `идея`, если сомневаемся, нужно ли) | очистить `Исполнитель`; в описании карточки записать, где остановились |

## Перед началом работы
1. Найди карточку: по полю `Ветка` (имя твоей ветки) или по смыслу задачи. Запрос: `SELECT url, "Задача", "Статус", "Исполнитель" FROM "collection://418ab976-afd8-81a2-a543-000b62d2cf1f" WHERE "Ветка" = ?`.
2. Карточка есть и свободна (`можно брать`, исполнителя нет) → бери: `в работе`, свой человек в `Исполнитель`, имя ветки в `Ветка`.
3. Карточка уже `в работе` у другого → не бери, договорись с ним.
4. Карточки нет → заведи до первого коммита: `Статус` = `в работе`, `Вне плана` = да (если задачи не было в обсуждённом плане), `Создано` = сегодня, `Ветка`, `Исполнитель`, `Область`, `Приоритет`. В описании: что сделать и что значит «готово».

## Работа в Notion через коннектор
- Создать карточку: `notion-create-pages` с `parent: {"type":"data_source_id","data_source_id":"418ab976-afd8-81a2-a543-000b62d2cf1f"}`. Свойства: `"Задача"`, `"Статус"`, `"Исполнитель"`, `"Область"`, `"Приоритет"`, `"Ветка"`, `"PR"` (число), `"date:Создано:start"` (ГГГГ-ММ-ДД), `"Вне плана"` (`__YES__` / `__NO__`).
- Сменить статус или поле: `notion-update-page`, команда `update_properties`, например `{"Статус":"на проверке","PR":27}`. Дату готовности пиши как `"date:Готово:start"`.
- Описание карточки (что сделать, чекбоксы) — содержимое страницы карточки.
- Если коннектора Notion у тебя нет: в конце ответа скажи человеку, какую карточку и в какой статус перевести, и вставь в описание PR строку «Задача: <ссылка на карточку>» (или «карточки нет, нужна новая: …»).

## Поля
- `Статус`: `идея` (не решено, делать ли) · `можно брать` (решено, свободно) · `в работе` · `на проверке` (PR открыт) · `готово`.
- `Исполнитель`: Глеб, Виталий, Захар, Викентий. Новый человек = новая опция в базе. ИИ ставит имя своего человека, не своё.
- `Область`: бой, мир и карта, фракции и баланс, спутники, герой и снаряжение, интерфейс, графика, звук, мультиплеер, порт, релиз, процесс. Новая область можно, но сперва глянь, нет ли подходящей.
- `Приоритет`: высокий / обычный / низкий. `Вне плана`: галочка для задач, заведённых по ходу работы.

## Правила
- Задачи по мультиплееру (`Область` = мультиплеер) берёт только Глеб.
- Идею, которая меняет концепцию игры, заводи как `идея` и спроси Глеба, не начинай делать.
- Чужие карточки не удаляем и не переименовываем. Неактуальное — `идея` и пометка в описании. Удаляет только Глеб.
- Большую задачу разбей на несколько карточек и перечисли их в описании главной.
- `готово` ставь только когда PR слит или вот-вот сливается этим PR.
