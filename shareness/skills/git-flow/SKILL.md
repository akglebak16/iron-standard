---
name: git-flow
description: Ветки, коммиты и слияние в main с деплоем на GitHub Pages. Применять при пуше и слиянии.
---
1. Работай в своей ветке, не в `main`. Имя по смыслу (`graphics-overhaul`, `companion-vikenty`). Пушить в `main` напрямую нельзя никому; свою ветку пушь сколько угодно (`git push -u origin <ветка>`), ИИ может делать это сам, не спрашивая.
2. Перед пушем: `node build.mjs`, `npm test` (см. навык `build-and-test`), запись в `CHANGELOG.md`.
3. Коммит: короткое русское описание, что изменилось.
4. В `main` — только через Pull Request из ветки (`gh pr create --base main`), сливает Глеб после зелёных тестов. CI («Сборка и проверка») соберёт игру, прогонит тесты и выложит на Pages.
5. Правки мультиплеера идут только от Глеба.
6. Не слей в `main` то, что ломает игру, сохранения или тесты, и то, что меняет игру целиком (другая эпоха, жанр, шутер, огнестрел вместо средневековья), без явного «да» Глеба (см. «Жёсткие правила» в `CLAUDE.md`).
