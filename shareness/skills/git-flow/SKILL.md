---
name: git-flow
description: Ветки, коммиты и слияние в main с деплоем на GitHub Pages. Применять при пуше и слиянии.
---
1. Работай в своей ветке, не в `main`. Имя по смыслу (`graphics-overhaul`, `companion-vikenty`).
2. Перед пушем: `node build.mjs`, `npm test` (см. навык `build-and-test`), запись в `CHANGELOG.md`.
3. Коммит: короткое русское описание, что изменилось.
4. В `main` — через Pull Request или (для владельца) быстрое слияние после зелёных тестов. CI («Сборка и проверка») соберёт игру, прогонит тесты и выложит на Pages.
5. Правки мультиплеера идут только от Глеба.
6. Не слей в `main` то, что ломает игру, сохранения или тесты, и крупную смену концепции без согласия Глеба (см. «Жёсткие правила» в `CLAUDE.md`).
