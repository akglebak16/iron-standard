# shareness — общая память проекта для всех ИИ и людей

Сюда ссылаются `CLAUDE.md` (Claude Code), `AGENTS.md` (Codex и другие) и `.cursor/rules/shareness.mdc` (Cursor). Один набор знаний на всех.

## Что тут лежит
- `lessons.md` — короткие уроки: грабли, решения, договорённости. Пополняется по ходу работы.
- `skills/<имя>/SKILL.md` — повторяемые процедуры по шагам:
  - `build-and-test` — собрать игру, прогнать тесты, снять скриншоты;
  - `changelog` — как описывать изменения для игрока (PR → Releases);
  - `graphics` — как устроена графика (спрайты, иконки, анимации) и что нельзя ломать;
  - `git-flow` — ветки, коммиты, слияние в `main`, деплой.

## Как пополнять
- Урок: одна строка в `lessons.md` под нужным заголовком, с датой. Что случилось → что делать.
- Навык: новая папка `skills/<имя>/` с `SKILL.md` (шапка `name`, `description`, затем шаги). Описание — одной фразой «когда применять».
- Не дублируй: если пункт уже есть, поправь его. Устаревшее удаляй.
- Лишнего не пиши: секреты, пароли, личные данные и ключи сюда не попадают.
- Правки `shareness/` идут тем же коммитом, что и код, или отдельным коротким коммитом.

## Для разных агентов
- Claude Code: навыки можно подключить копированием папки в `.claude/skills/` или читать напрямую по ссылке из `CLAUDE.md`.
- Codex и прочие: читают `AGENTS.md`, дальше идут сюда.
- Cursor: правило `.cursor/rules/shareness.mdc` направляет сюда.
