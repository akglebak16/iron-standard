＋ Новая задача
Правила коротко (полностью — shareness/skills/роудмап-разработки):
  1. Каждая задача — файл roadmap/tasks/<имя>.md со шапкой: название, статус, кто делает, область.
  2. Взял задачу — в своей ветке поставь status: в работе и owner, запушь ветку. Здесь карточка переедет в «В работе» с меткой ветки.
  3. Делаешь что-то, чего нет в списке, — заведи файл задачи в той же ветке, с outside: да.
  4. Открыл PR — на проверке и номер pr; в последнем коммите перед слиянием — готово и дата done.
  5. Кнопка «Изменить на GitHub» в карточке открывает файл в редакторе GitHub: правишь статус, GitHub сам предложит ветку и PR.
