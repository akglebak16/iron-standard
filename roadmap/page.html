Готово
Как пользоваться (полностью — правило роудмапа):
  1. Один раз нажми на свой профиль справа сверху: выбери себя и вставь токен GitHub. Без токена доска только для просмотра.
  2. Тащи карточки между колонками мышкой (на телефоне — кнопки ‹ ›). Клик по кружку на карточке меняет исполнителя, «Взять» ставит задачу на тебя.
  3. Клик по карточке открывает её: там можно поменять всё и описание.
  4. Любое изменение сразу пишется в ветку roadmap-board и видно всем после пересборки сайта (пара минут). Чтобы оно попало в main, Глеб сливает Pull Request из этой ветки.
  5. Сделал что-то, чего нет в списке, — «＋ Новая задача» и галочка «вне плана».
