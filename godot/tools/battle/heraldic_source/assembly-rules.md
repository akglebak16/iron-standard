# Доминион: правила сборки бойца из частей

Инструкция для ИИ, который собирает `dominion_heraldic_*.png` из нарисованных частей
(`render_heraldic_faction.cjs dominion`; особый сустав Доминиона — `joint` в `FACTIONS.dominion`). Итог обязан выглядеть как один цельный боец, нарисованный
сразу: без щелей, без двойных контуров, без того, чтобы одна часть «проваливалась» в другую.

## Части и система координат
- Кадр 152×176, прозрачный фон. Ноги (анкер) в точке (76, 158), шея в общей точке (76, 78).
- `torsos.png`: туловище без головы и без щита. На месте шеи — вырез воротника; его тёмная
  полость вычищается до прозрачности, центр выреза ставится в (76, 78).
- `heads.png`: голова с короткой шеей. Середина низа шеи ставится в x = 76, низ шеи на
  `NECK_TUCK` px ниже точки шеи, чтобы срез прятался за передним краем воротника.
- `shields.png`: щит целиком. Вписывается в форму из `SHIELDS` (круг или капля) на левой
  от зрителя стороне груди.
- Кровь вместо культи: заливка выреза воротника у тела без головы и низ шеи у отрубленной
  головы (рисуется кодом по форме самих частей, перспектива всегда совпадает).
- Оружие с кистями (`weapons.png`, `gloves.png`) — отдельный слой, правая от зрителя сторона.

## Порядок слоёв (снизу вверх)
| Состояние | Слои |
|---|---|
| живой боец (`body`) | туловище → голова → передняя половина воротника → щит |
| без щита (`bare`, для блока) | туловище → голова → передняя половина воротника |
| щит (`shield`) | только щит |
| без головы (`headless`) | кровь в вырезе → туловище → щит |
| голова (`head`) | голова, низ шеи залит кровью |
| портрет и труп | `body` → оружие с кистями |

Почему так («кукольный» сустав): голова лежит поверх задней части воротника, а передняя
половина воротника (ниже центра выреза) кладётся поверх шеи — шея уходит внутрь воротника,
задний край не перечёркивает шею. Щит всегда сверху туловища. Оружие и кисти — над всем.

## Что проверять после сборки
1. Нет щелей: в `body` между подбородком и воротником не просвечивает фон, вырез закрыт шеей.
2. Нет коллизий: ничто не торчит поверх лица или шлема; полы бармицы не налезают на щит
   спереди; кисть с оружием не перекрывает лицо; щит не закрывает пряжку наполовину криво.
3. Масштаб: туловище ~108 px шириной, голова ~64 px высотой — пропорции как у прежних
   цельных бюстов (сравнить рядом с `body.png`).
4. Один кусок: у `head` нет оторванных пылинок, у `headless` кровь видна только в вырезе.
5. `bare` + `shield` попиксельно дают `body` (тест `test_shield_guard`).
6. Голова кончается не ниже 83 px, центр щита лежит на щите (`test_dominion_heraldic`).
7. Визуально: превью `tools/battle/dominion_preview.gd` и `dominion_head_preview.gd`,
   оба направления, отрубание головы, блок щитом, найм под знаменем игрока.

## Если части новые
Не подгонять руками. Менять только числа сборки (`TORSO_WIDTH`, `HEAD_HEIGHT`, `NECK_TUCK`,
`SHIELDS`) и смотреть превью; плохо нарисованную часть — перегенерировать по
`parts-prompts.md`, а не латать пикселями.
