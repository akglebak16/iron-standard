# Эталон перед техническим этапом после паритета боя

Снято 2026-11-15, Godot 4.7.2, Linux, программный рендер (Mesa llvmpipe, Xvfb, 2 ядра). Нужен для шага 1 из [плана](../../battle/POST_PARITY_PLAN.md): после каждого изменения повторять те же проверки и сравнивать.

## Проверки

1. Тесты: `node godot/tools/test.cjs <godot>` — 53 теста, все зелёные.
2. Кадры и время кадра (с рендером, не `--headless`):

   ```text
   xvfb-run -a -s "-screen 0 1280x720x24" godot --path godot --fixed-fps 60 --disable-vsync \
     --audio-driver Dummy --resolution 1280x720 --script res://tools/baseline_capture.gd -- \
     --scene=res://app/main.tscn --out=/tmp/now --reference=godot/tools/baseline
   ```

   То же для `res://app/siege_demo.tscn`. Скрипт отдаёт сцене одинаковый ввод (4 шага отдаления камеры, затем приказ «атаковать»), сохраняет кадры 2/300/900/1500 и считает долю отличающихся пикселей с эталоном. В репозитории лежат кадры 300 и 1500 (по ним идёт сравнение); кадры 2 и 900 скрипт сохраняет, но сравнивает только при наличии файла в эталоне.
3. CPU симуляции без графики: `godot --headless --path godot --script res://battle/tools/benchmark.gd`.

## Замеры

| Сцена | Запуск до первого кадра | Кадр, среднее | Кадр, p95 |
| --- | --- | --- | --- |
| `main.tscn` (поле) | ~1,0–1,5 с | ~40 мс | ~52 мс |
| `siege_demo.tscn` (осада) | ~0,9–1,0 с | ~50 мс | ~61 мс |

Бенчмарк симуляции (3 прогона): 24 на 24 — 1,25–1,29 мс/тик, снимок 0,27–0,32 мс; 300 на 300 — 19,9–24,9 мс/тик, снимок 3,5–4,4 мс (почти всё — движение и атаки).

## Как читать

- Время кадра снято на программном рендере: оно годится только для сравнения до/после на том же окружении, не как оценка железа игрока. На обычной видеокарте цифры будут другими.
- Первая секунда кадров с максимумом 400–600 мс — загрузка шейдеров и текстур, в среднее не влияет на выводы.
- Кадры 2 и 300 повторяются попиксельно (0,00%). К 900-му кадру появляется 0,2–0,8% отличий: эффекты и случайные детали вне симуляции. Допуск при сравнении — единицы процентов; заметный скачок означает изменение картинки.
