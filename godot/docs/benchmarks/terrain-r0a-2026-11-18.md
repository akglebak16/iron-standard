# Местность боя, этап Р0а: размер поля по численности, 18 ноября 2026

Задача #192, план — [TERRAIN.md](../modules/battle/TERRAIN.md), разделы 5 и 9. Бой 1000×1000 после Р0а идёт на поле
4600×3000 вместо 2600×1700. Здесь — его цена в симуляции и отрисовке против `main`.

## Условия

AMD Ryzen 7 5700X (8 ядер, 16 потоков), NVIDIA GeForce RTX 3060, Windows 10 Home 10.0.19045, Godot 4.7.2 из Steam. Обе
сборки — `node godot/tools/release.cjs`, release-smoke прошёл, `debug=false`.

| Сборка | Ревизия | Поле 1000×1000 |
|---|---|---|
| база | `origin/main` `f2f08f4`, отдельный `git worktree` | 2600×1700 |
| Р0а | ветка `claude/terrain-r0a-arena-size` | 4600×3000 |

В базе к арене добавлены только метрики Р0а (`battle_arena.gd`, версия 5), игровой код — `main`. Других процессов Godot
во время замеров не было.

## Симуляция: `benchmark.cjs`, медиана пяти повторов, мс

`--n=1000 --ticks=3600 --warmup=120 --seed=4242 --profile-phases --repeat=5 --execution-context=host`, порядок сборок
чередовался по сценариям. Данные — [terrain-r0a-2026-11-18-cpu.json](terrain-r0a-2026-11-18-cpu.json).

| Сценарий | p95 тика: база → Р0а | Среднее тика | Снимок, p95 |
|---|---|---|---|
| Конница | 5,87 → **5,75** (5,84–5,96 → 5,70–5,80) | 2,55 → 2,82 | 1,11 → 1,11 |
| Сближение | 3,51 → 3,62 (3,48–3,53 → 3,60–3,64) | 1,77 → 1,84 | 1,11 → 1,13 |
| Плотный контакт | 3,35 → 3,43 (3,35–3,36 → 3,40–3,46) | 1,72 → 1,72 | 1,11 → 1,11 |
| Смешанный | 4,12 → 4,10 (4,11–4,14 → 4,09–4,15) | 2,31 → 2,17 | 1,24 → 1,28 |

- Бюджет p95 тика 6 мс держится везде; конница, которая была у края (5,9), стала чуть ниже.
- Плотные сценарии (`contact`, `cavalry`) в `battle_benchmark.gd` теперь ставят блок в середину поля: на 2600×1700
  координаты прежние, на большом поле — со сдвигом `(arena - 2600×1700) / 2`. Бой другой (шире поле, другие края),
  поэтому разница — не цена кода, а цена другого боя. Сетки индексов и native-контактов растут с полем, перебор соседей
  не дорожает.

## Отрисовка: `--view-benchmark`, окно 1920×1080, 30 с

`IronStandard.exe --resolution 1920x1080 --disable-vsync --max-fps 0 -- --view-benchmark --measure-seconds=30
--mode=battle --n=1000 --audio=on --seed=4242`, по три прогона вперемешку. `wide` — зум 0,55 в центре поля, `field` —
новый предел отдаления (всё поле в кадре, зум 0,35). Данные — [terrain-r0a-2026-11-18-view.json](terrain-r0a-2026-11-18-view.json).

| Сборка, камера | Кадр, среднее, мс | p95 | p99 | Рисование, мс | Draw calls | Видеопамять |
|---|---|---|---|---|---|---|
| база, `wide` | 5,70 / 5,64 / 5,64 | 8,28 / 8,03 / 8,01 | 10,3 / 9,8 / 9,8 | 2,74 | 377 | 1115–1119 МБ |
| Р0а, `wide` | 5,16 / 5,18 | 8,01 / 8,11 | 9,7 / 10,2 | 2,50 | 316 | 1190–1194 МБ |
| Р0а, `field` | 5,83 / 5,49 / 5,50 | 9,36 / 8,14 / 8,14 | 12,4 / 9,9 / 9,9 | 2,66–2,78 | 364 | 1186–1190 МБ |

- Просадки FPS нет: при том же зуме кадр дешевле (на большом поле в кадре меньше бойцов), всё поле целиком стоит как
  база с зумом 0,55. Первый прогон `field` — холодный старт (9,4 мс p95), повторы — 8,1.
- Видеопамять +70 МБ: запечённый слой следов и трупов (`ground_bake.gd`) — текстура размером с поле, 4600×3000 вместо
  2600×1700.
