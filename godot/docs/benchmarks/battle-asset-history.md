# Историческая проверка ассетов боя

Результаты прежнего этапа до новой архитектурной миграции. Это не план работ
и не текущий Windows performance baseline. Действующий план —
[MIGRATION.md](../architecture/MIGRATION.md).

Собственная музыка боя и текстуры осадной стены сохранены; источники и лицензии
описаны в [ASSETS.md](../ASSETS.md). Текстурная стена получает геометрию симуляции,
но не определяет её. При нецелом масштабе линейная фильтрация сохраняет тонкие
линии; nearest может их терять.

Старые Linux/Mesa llvmpipe замеры осады: ~48–50 мс для стены кодом и ~47–48 мс
для текстурной стены. Различие находится в шуме; оно не доказывает ускорение
Windows-сборки. Эталонные кадры и методика находятся в
[tools/baseline](../../tools/baseline/README.md).

При разделении прежних крупных функций фабрики, снимков, осадной обороны и
добычи отпечатки поведения демобоя/осады сохранялись. История полного старого
плана доступна в Git; повторно переносить уже работающую кампанию по нему нельзя.
