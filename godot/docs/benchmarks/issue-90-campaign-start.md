# Создание новой кампании (#90)

Диагностический замер до оптимизации. Основа `origin/main` — `2e1ef3fc`
с добавленными метками времени. Windows Release, Godot 4.7.2, i5-14400F,
RTX 4070 SUPER, 1920×1080, VSync выключен, seed 4242. Обе кампании создали
85 отрядов. Первый замер — первая кампания в новом процессе, повторный —
вторая кампания в том же процессе после возврата в меню. Дисковый кэш ОС
не сбрасывался.

```powershell
node godot/tools/release.cjs dist/godot/toolchain/Godot_v4.7.2-stable_win64_console.exe
.\dist\godot\migration-release\IronStandard.exe --resolution 1920x1080 --disable-vsync --max-fps 0 -- --campaign-start-benchmark
```

Сценарий проходит через меню создания героя. Конец замера — первый кадр
после готовности карты и включения управления. Время по этапам в миллисекундах.

| Этап | Первый | Повторный |
|---|---:|---:|
| От «В путь» до готовности каталогов | 34 | 12 |
| Создание мира и партий | 2513 | 2505 |
| Подготовка узлов и ресурсов карты | 441 | 422 |
| Создание интерфейса | 35 | 16 |
| Ожидание запекания карты после готовности интерфейса | 698 | 240 |
| От завершения запекания до первого готового кадра | 75 | 69 |
| **Всего** | **3797** | **3264** |

Следующий замер должен отдельно выделить генерацию рельефа, поселений,
маршрутов и создание отрядов внутри `WorldState.create`.
