# ADR-016: расталкивание совпавших центров

При точно совпавших центрах прежняя нормаль была нулевой; умножение на
глубину пересечения не двигало ни одного бойца. Теперь направление такой
пары равно Vector2.RIGHT. Порядок пары сохраняется стабильным активным
массивом. Нормаль не требует RNG, зависит только от геометрии пары и
одинакова в plain GDScript, packed GDScript и чистом native solver.

Массовые коэффициенты и сила контакта сохраняются. Для любых несовпавших
координат формула прежняя. Это намеренное исправление вырожденной геометрии,
а не заявление о побитовом совпадении старого алгоритма на всех входах.

`test_coincident_contacts.gd` проверяет разделение пары, массовый центр,
меньшее смещение тяжёлого бойца, точное равенство трёх backend, конечность
и границы поля у стопки из 96 бойцов на 30 последовательных проходах.
Все бойцы остаются активными; два native-контекста воспроизводят результат.
Фиксированное направление может создавать направленную структуру в
искусственно совпавшей толпе; отсутствие всех пересечений за один проход
не гарантируется и не требуется мягким итерационным solver.

Проверки: новый crowd-тест, native differential (поле/осада), движение,
полный indexed/exhaustive бой; Windows release-smoke и архитектурный gate.
Прежние fingerprints обычных полевого и осадного сценариев сохранены.

Короткий release contact 1000×1000, 60/180 ticks, два повтора на P-ядрах:
tick p95 23,715/23,737 мс, snapshot p95 3,293/3,368 мс. Методика sampling v2
уже прогревает снимки. Отчёт: `../benchmarks/coincident-sampling-v2-pcore.json`.
Это диагностические CPU-прогоны; пороги 6/1 мс и графическая приёмка не закрыты.

Расширенная сверка со старым pre-index fixture обнаружила ожидаемое расхождение
на точных стопках (seed 7, tick 0). Исторический solver сохраняет исходное
поведение по умолчанию; отдельный параметр включает только ненулевую нормаль.
Differential-тест теперь прогоняет обычную и совпавшую расстановку отдельно
для всех трёх seeds и обеих плотностей. Все прежние сравнения RNG, снарядов,
координат, направлений, HP и таймеров сохранены. Отдельно проверяется, что
исторический режим по-прежнему оставляет точную пару неподвижной.
