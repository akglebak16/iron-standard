# ADR-012: поколения ссылок боевых целей

Ссылки AI и подготовленного удара больше не хранят индекс массива.
`GenerationHandles` владеет таблицами slot → generation/index и index → slot.
Handle — 64-битное целое: старшие 31 бита поколения, младшие 32 бита slot+1;
ноль означает отсутствие цели. Пространство идентичности ограничено одним
контекстом боя; это не глобальный CharacterId и не значение для сохранения мира.

Смерть или выход с поля освобождает handle сразу. Повторное использование
слота повышает поколение; старый удар не может попасть в подкрепление,
занявшее слот. При исчерпании поколения слот навсегда выводится из обращения.
`relocate` меняет плотный индекс, сохраняя handle. Пул не удерживает Unit/State.
Повторное включение Unit и включение в другой контекст отклоняется в release.

Production Targeting/CombatStep разрешают цели только через `State.unit_for`.
Возврат target_index/ai_wind_target_index запрещён анализатором, включая
строковый set. Прежние тесты выбора целей и боевых окон переведены на handle
без удаления проверок; differential-сценарии сравнивают поколение цели тоже.

Это часть этапа 2. Unit пока остаётся объектом, State.units хранит историю,
а battle_index используется пространственными рабочими индексами и снимками.
Авторитетные SoA, уплотнение активных колонок и архив результата ещё нужны;
наличие пула поколений не закрывает требование BATTLE-SOA-HANDLES целиком.

Проверки: 89 файлов Godot-тестов, release-smoke и прежние fingerprints поля/
осады прошли. Первое короткое измерение (24.528/28.047 мс) превысило предыдущие
18.935/21.129 мс больше чем на 10%; этап был задержан для сравнения.
В трёх чередующихся запусках прежнего native baseline из Git-архива и handles
на P-ядрах получено 27.323/24.748, 28.153/24.948, 23.140/24.573 мс p95 тика
(baseline/handles). Одновременно менялась стоимость неизменённого снимка.
Регрессия >10% в этом сравнении не воспроизвелась; точную внешнюю причину
колебания скорости не установили. Это не подтверждение общих performance-порогов.
Все результаты, включая первые медленные запуски, сохранены в
`../benchmarks/generation-handles-initial.json` и `generation-handles-ab.json`.
