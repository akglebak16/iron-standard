# ADR-004: загрузка определений через adapter

Семь каталогов больше не открывают файлы. Они реализуют `replace_data(values)`
и возвращают статус валидации, не заменяя рабочие данные при ошибке. Пути и
чтение JSON находятся в `adapters/content/catalog_loader.gd`. Объект EuropeData
тоже получает значения, а не читает ресурс при создании мира.

`WorldState.create(seed, europe, culture, definitions)` требует готовые каталоги.
`PartyRoster` получает войска и фракции в конструкторе. Persistence-код принимает
те же определения при восстановлении v1/v2; чтение файлов остаётся снаружи.
Registry создаётся целиком и публикуется только после успешной валидации всех
каталогов. Перед внедрением каталоги запечатываются: повторный replace_data
отклоняется, вложенные контейнеры делаются read-only. Контексты получают
отдельные экземпляры. FactionCatalog теперь отдаёт отделённые копии, как другие
каталоги.

Для миграции сохранены имена и схемы определений, RNG-порядок генерации мира
и поля старых сценариев. Разделение игровых/визуальных схем и перенос всех
вызовов загрузчика из UI в composition root остаются отдельными условиями
CONTENT-REGISTRY. Этот шаг сам по себе их не закрывает.
