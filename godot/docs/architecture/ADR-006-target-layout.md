# ADR-006: перенос в целевые каталоги

После отделения I/O каталогов и editor Resource перенесены 336 файлов.

- `core/{battle,campaign,troops,equipment,characters}` — прежние владельцы правил.
- `content/gameplay/<владелец>` — прежние JSON; `content/scenarios` — сценарии.
- `tests/unit/<владелец>` — прежние модульные тесты и fixtures.
- `tools/<владелец>` — экспортёры и измерительные инструменты.
- `docs/modules/<владелец>` — документы модулей.
- `adapters/persistence/save_store.gd` — поколения файлов сохранений.

Этот коммит меняет расположение, ссылки и связанные проверки структуры.
Игровые алгоритмы не меняются. Манифест объединяет прежнюю временную область
battle-api с модулем battle, запрещает старые корни и сохраняет проверку циклов.
Широкие точки входа application боя и кампании остаются явно отмеченной работой
по сужению API, а не скрытым архитектурным исключением.

`file-inventory.json` сохраняет исходные source и обновляет destination.
`domain-relocation.json` хранит SHA исходного коммита и хэши перемещённых файлов.
Отдельно обновлены разделённые сегменты path.join в export_world и команды CI.
Исторический presentation-relocation и исходный BLUEPRINT не переписываются.

Fingerprints до/после:

```text
FP demo_battle.tres 55 1200 1965093033 313120297 5864093
FP demo_siege.tres 53 1200 3285071689 402878887 5864093
```

Смена путей не означает приёмку производительности 1000×1000. Требования SoA,
AI/маршрутов, полного Campaign API и performance-матрицы продолжают проверяться
отдельно через requirements.json.
