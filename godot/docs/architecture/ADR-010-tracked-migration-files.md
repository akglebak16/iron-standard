# ADR-010: проверка файлов, скрытых от Git

При контрольной проверке обнаружено, что прежнее правило `.gitignore` `data/`
распространялось на каталоги любого уровня. Старые исключения перечисляли
прежние Godot-пути, поэтому после перемещения 38 файлов новых `core/*/data`
и `tests/unit/*/data` остались на диске, но не попали в коммит переноса.
Локальные Godot-тесты и проверка существования destination этого не выявляли.

Правило сужено до `/data/` — корневого каталога серверных данных. Каталоги
Godot больше не требуют исключений. Все пропущенные скрипты, UID и проверки
добавлены без изменения содержимого. Исторический реестр переноса сохраняется.

Architecture checker теперь передаёт исходники и destination реестра в
`git check-ignore --no-index`: запрещено скрывать их даже правилом, которое
пока не влияет на уже отслеживаемые файлы. Одного `exists()` недостаточно.
Дополнительная проверка — импорт/сценарии из чистого `git archive` коммита;
она не использует неотслеживаемые файлы рабочего checkout.
