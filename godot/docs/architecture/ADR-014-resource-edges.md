# ADR-014: граф включает ресурсы и native extension

После появления GDExtension обнаружен пропуск: сборщик видел .gdextension,
но граф разрешал только ссылки на gd/tscn/tres/C++ и мог пропустить preload
расширения через UID. Аналогично двоичные изображения/звук не были вершинами.

Расширены collect и построение рёбер: GDExtension, JSON, ресурсы, текстуры,
аудио и шрифты. Двоичные файлы учитываются по пути, без токенизации содержимого.
UID импортируемых ассетов читается из .import; пути generated import cache
не являются исходниками. Генерируемые DLL не включаются в граф исходников:
они проверяются сборкой и хэшами release manifest.

Прямой либо UID preload этих ресурсов из pure core/runtime запрещён;
транзитивный helper также не скрывает зависимость. Отрицательные fixtures
проверяют изображение, UID изображения, UID GDExtension, JSON helper и
отсутствующий звук. Документация/отчёты не анализируются как исполняемый контент.

Теперь видны реальные чтения JSON из catalog_loader. Манифест разделяет
gameplay-content (определения без исходящих зависимостей) и scenario-content
(editor Resource с зависимостью от adapters). Loader может читать определения,
composition root — сценарии. Это отражает разные обязанности и исключает
искусственный цикл umbrella-модуля content с adapters без исключений анализатора.
Подсчёт строк токенизатора также переведён с квадратичного на линейный обход,
чтобы большие JSON-каталоги не делали архитектурную проверку непрактичной.
