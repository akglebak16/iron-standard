# ADR-025: native-ядро шага мира кампании

Шаг мира идёт в рабочем потоке (ADR-024), но в кризис нежити (seed 11, дни 50–80,
~120 отрядов) стоит в среднем 7–8 мс на облачном CPU. Замер по фазам: оценка
целей ИИ — 65% тика, внутри неё ~17% приходится на пересборку карты угроз
(ADR-023: каждый шаг все отряды штампуются в сетку), поиск соприкосновений
перебором всех пар — 11%. Решение владельца: горячие места шага мира переносим
в C++ по образцу ADR-011 (#240).

Первая часть переносит два плотных числовых цикла:
- штамп слоёв карты угроз (`threat_map.gd` `rebuild`/`_stamp`);
- поиск пар отрядов ближе `PartyAI.CONTACT_REACH` (`party_ai.gd` `step`).

Ядро `core/campaign/world/native/world_kernel.hpp` — чистый C++ без заголовков
движка, часов, файлов и изменяемого статического состояния. Регистрация класса
`IronWorldKernel`, проверка размеров и преобразование packed-массивов — в
`adapters/godot/native/world_adapter.cpp`. Публичный порт
`adapters/godot/native/world.gd` создаётся в composition root
(`world_demo.gd`, `WorldState.use_native`) и держит счётчики вызовов и отказов.
Домен получает порт параметром и не знает об адаптерах; без библиотеки порт
равен null и шаг идёт по эталонному GDScript.

Ядро повторяет порядок и типы эталона: источники штампуются в порядке списка в слой
своей фракции (слои — по отсортированным именам), арифметика в double, клетка
сетки — float32 (чтение, сложение в double, запись), длина `Vector2` — float32 с
float32-корнем; FMA contraction выключена флагами сборки. Native-путь отдаёт
только геометрию пар: флаги, членство в roster и враждебность меняются по ходу
фазы, поэтому их проверяет GDScript в прежнем порядке, а `break` после первого
боя заменён пропуском оставшихся пар того же отряда.

Приёмка — `tests/integration/test_native_world.gd`: шесть случайных раскладок
источников (за краем карты, нулевая и отрицательная сила) совпадают с эталоном
клетка в клетку; пары у самого порога совпадают по составу и порядку; кампания
seed 11 с native и без него совпадает каждый день 15 дней по SHA сохранения и
состоянию RNG, отказов native нет. `campaign_step_probe.gd --native` требует
загруженную библиотеку и печатает счётчики.

Замер (облачный CPU, два прогона с чередованием порядка, дни 50–80): средний шаг
7,99/7,58 мс → 6,24/6,35 мс, шагов дольше 20 мс 24/14 → 12/10.

Следующая часть — оценка целей ИИ (`party_goals.candidates`) на плотных колонках
отрядов; пока она остаётся GDScript.
