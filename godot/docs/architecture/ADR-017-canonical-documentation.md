# ADR-017: единый источник Godot-документации

2026-11-15. Решение владельца: удалить legacy Markdown и правила из корня Godot,
направить Claude и остальных помощников к docs и blueprint.

`docs/README.md` — точка входа, BLUEPRINT — архитектурный контракт,
MIGRATION — актуальные этапы/незакрытые требования, DEVELOPMENT — процедура
разработки. Паритет механик перенесён в docs/modules/PARITY_CHECKLIST.md,
источники ассетов — в docs/ASSETS.md, зависимости — в docs/DEPENDENCIES.md.
Прежний POST_PARITY_PLAN заменён краткой историей измерений без указаний
повторно переносить уже реализованную кампанию. Исторические source в реестре
переноса и прежние relocation hashes сохраняются; destination обновлены.

Корневые AGENTS.md и CLAUDE.md обязаны ссылаться на четыре главных документа.
Architecture gate запрещает возврат удалённых файлов и отсутствие обязательных
документов/ссылок. Отрицательные fixtures проверяют эти нарушения.
Blueprint, границы модулей и критерии performance этой уборкой не ослабляются.
