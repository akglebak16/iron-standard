# ADR-011: пакетное native-ядро контактов

После локальных spatial queries и переиспользования рабочих массивов симуляция
сценария contact 1000×1000 остаётся около 33 мс p95 на P-ядрах; исходный профиль контактов был
около 16 мс. Условие плана для проверки отдельного C++-участка выполнено.

Эксперимент переносит только контактную фазу. `runtime/simulation/native`
использует стандартные контейнеры и числовые значения, не включает godot-cpp,
не читает часы/файлы, не хранит изменяемого статического состояния. Godot-типы,
регистрация класса, проверка размеров и преобразование массивов принадлежат
`adapters/godot/native`. Вызов выполняется пакетом для всей фазы.

Расширение получает геометрию и параметры правил; параметры не копируются
магическими числами из Config. Порядок пар и операций сохраняется, fast-math
и FMA contraction выключены. GDScript solver остаётся эталоном для сравнения.
Приёмка native-участка требует differential tests поля/осады, fingerprint,
release-smoke и измерения на прежнем составе. До этих проверок эксперимент
не считается внедрённой оптимизацией и не закрывает performance-требование.

Differential test сравнивает поле и осаду по 900 тиков, позиции/скорости,
боевые поля, RNG и события каждого тика. Перед этим проверяются десять плотных
и разреженных раскладок с совпавшими позициями, неактивными юнитами и выходом
за поле. Тест прошёл. Порт внедрён через Factory из composition root;
его замыкание удерживает RefCounted-адаптер до освобождения контекста.
GDScript используется для небольших боёв и остаётся сравнительным backend.
Benchmark явно записывает backend, число native-проходов и отказов; запрос
native без загруженной библиотеки или с fallback считается ошибкой.

Зависимости закреплены: LLVM-MinGW 20260908, godot-cpp 10.0.0 (API 4.7),
переносимый Python 3.13.17 для генератора. Всё размещается в dist; системный
PATH не меняется. Ядро компилируется без заголовков движка; bindings используются
только адаптером. Генерируемая DLL не коммитится.

В чистой копии сначала выполнить `pwsh -File godot/tools/native_bootstrap.ps1`.
Скачанные архивы проверяются по SHA256 из native_dependencies.json. Test/release
runner собирает DLL перед импортом; повторная сборка кешируется. Релиз включает
лицензии godot-cpp/LLVM и SHA каждой DLL рядом с SHA exe в build manifest.
Изменённая DLL делает benchmark недействительным даже при прежнем exe.

Анализатор расширен на C++ includes и .gdextension: проверяет относительные
зависимости, транзитивную нечистоту, запрещает engine/I/O-заголовки и изменяемые
static-данные в runtime/core. ClassDB/GDExtensionManager также запрещены в
чистом GDScript. Манифест разрешает adapters → runtime и конкретный порт contacts.
