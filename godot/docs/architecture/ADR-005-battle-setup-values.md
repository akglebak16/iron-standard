# ADR-005: BattleSetup как чистые значения

`battle/data/battle_setup.gd` теперь RefCounted с 17 полями встречи. Редакторская
обёртка Resource находится в `adapters/godot/resources/battle_setup_resource.gd`,
готовые сценарии — в `content/scenarios`. Composition root преобразует Resource
через `to_setup()` до вызова фабрики; словари и массивы копируются глубоко.
Изменение editor Resource после преобразования не меняет встречу. Данные кампании
создают BattleSetup напрямую, без Resource.

Имена полей, формулы лимитов/резервов и RNG-порядок не изменены. Fingerprints
поля и осады совпали с предыдущим коммитом. Это изменение границы данных,
а не изменение боевого алгоритма.

Анализатор проверяет чистоту всех старых доменных корней и core/runtime,
включая транзитивно достижимые helper-скрипты. Запрещены создание Resource,
SceneTree/Node, файловый доступ, ввод, dynamic load и изменяемое static-состояние.
Ссылки на классы, UID и ресурсы проходят тот же граф. Самопроверки включают
запрещённый helper вне pure-каталогов. Переезд самих модулей в core — следующий
механический этап, отдельно от изменения алгоритмов.
