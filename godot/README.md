# Железный Стяг на Godot

Запускаемый боевой прототип уже есть: Godot открывает встречу двух отрядов, показывает движение, атаки, конный натиск, мораль, бегство и результат. Бойцы пока обозначены простыми кругами; звук, подробная графика и другие правила исходного боя ещё требуют переноса. Кампания пока не перенесена.

Расположение кода и правила для разработчиков описаны в `ARCHITECTURE.md`. Внутри `battle/`: `application/` — сессия и команды, `model/` — состояние и сущности, `rules/` — действия и формулы, `data/` — войска, `presentation/` — сцена, `tests/` — проверки по тем же областям. Подробный статус переноса — в `MIGRATION_CHECKLIST.md`, сводка боя — в `battle/PARITY.md`, кандидаты на дополнительные библиотеки — в `DEPENDENCIES.md`.

Баланс боя хранится в `battle/config.gd`: размеры поля, построение, приказы, мораль, лимиты армий. Настройки запускаемой встречи лежат отдельно в `battle/data/demo_battle.tres` (можно редактировать в Inspector); временные цвета и подписи — в `battle/presentation/demo_config.gd`. Параметры каждого типа войск хранятся в `battle/data/troops.json`. Меняйте значения там, сохраняя поля и идентификаторы. Загрузчик каталога проверяет обязательные поля и допустимые параметры. Названия войск в JSON пока взяты из русской версии; при переносе интерфейса они получат ключи локализации.

`node godot/battle/tools/export_troops.cjs --check` сверяет каталог с исходным прототипом. Эта проверка полезна для контроля точности переноса и ожидаемо покажет разницу после намеренной правки баланса в Godot.

Версия движка: Godot 4.7.2. Откройте эту папку в редакторе Godot.

Проверка всех тестов Godot из корня репозитория: `node godot/tools/test.cjs <путь-к-godot.exe>`. Скрипт считает ошибки компиляции и зависание провалом теста, даже если Godot вернул код 0.

Примеры запуска отдельной проверки:

```text
godot --headless --path godot --script res://battle/tests/rules/test_damage.gd
godot --headless --path godot --script res://battle/tests/presentation/test_scene.gd
```

Измерение CPU без графики: `godot --headless --path godot --script res://battle/tools/benchmark.gd`. Текущий предел производительности большой армии и правила оптимизации записаны в `ARCHITECTURE.md`.
