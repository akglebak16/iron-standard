# Железный Стяг на Godot

Проект переноса находится на начальном этапе. Перенесены формула снижения урона бронёй, базовые правила получения урона, смерти, убийства и реакции морали ближайших бойцов, три группы и приказы, полный каталог из 67 типов войск и создание армий с лимитом фигур. Игровой бой и кампания ещё не перенесены.

Баланс боя хранится в `battle/config.gd`: размеры поля, построение, приказы, мораль, лимиты армий. Параметры каждого типа войск хранятся в `data/troops.json`. Меняйте значения там, сохраняя поля и идентификаторы. Загрузчик каталога проверяет обязательные поля и допустимые параметры. Названия войск в JSON пока взяты из русской версии; при переносе интерфейса они получат ключи локализации.

`node godot/tools/export_troops.cjs --check` сверяет каталог с исходным прототипом. Эта проверка полезна для контроля точности переноса и ожидаемо покажет разницу после намеренной правки баланса в Godot.

Версия движка: Godot 4.7.2. Откройте эту папку в редакторе Godot.

Проверки из корня репозитория:

```text
godot --headless --path godot --script res://tests/test_damage.gd
godot --headless --path godot --script res://tests/test_battle_state.gd
godot --headless --path godot --script res://tests/test_groups.gd
godot --headless --path godot --script res://tests/test_catalog_spawn.gd
```
