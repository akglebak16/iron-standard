# Временный подарок Викентию

Праздничное главное меню: поздравление, счастливый Викентий с баночкой «Счастье»,
Глебио слева и Захарий справа целуют именинника в щёки; сердечки, конфетти и Happy Birthday to You в собственной синтезированной аранжировке.
Не меняет персонажа в кампании, инвентарь, характеристики и игровые правила.

## Выключить или удалить

- Быстро выключить: `ENABLED := false` в `entry.gd`.
- Удалить полностью: убрать единственный вызов `birthday/entry.gd.mount` вместе
  с комментарием из `composition/main_menu.gd`, удалить эту папку и праздничный
  тест `tests/integration/app/test_birthday.gd` с UID и `tools/birthday/`. Обычное меню и его музыка
  восстановятся без других изменений.

Включение явное, без автоматической проверки даты и без правки сохранений.
Музыка учитывает оба пользовательских переключателя — звук и музыку; кнопка
внизу меняет сохранённую настройку музыки. Игровая музыка меню при празднике
останавливается. При выходе из меню праздничный плеер освобождается со сценой.

Облик берётся из каталога Викентия через существующие правила профиля и
экипировки. Праздничное лицо, поза и реквизит рисуются отдельно кодом Godot.
110 конфетти используют собственный фиксированный декоративный RNG.
Музыка создана `node godot/tools/birthday/render_music.cjs`; внешняя запись не используется.
