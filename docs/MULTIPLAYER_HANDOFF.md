# Промпт для продолжения: мультиплеер «Железного Стяга» (этапы 2–5)

Скопируй всё ниже в другую нейросеть (с доступом к репозиторию `akglebak16/iron-standard`, ветка `main`, и shell).

---

Ты продолжаешь браузерную игру «Железный Стяг» (инди-Bannerlord в стиле Battle Brothers: карта мира + бой армий в реальном времени). Язык интерфейса и общения с владельцем — русский, объясняй коротко и без жаргона. Сборка: `node build.mjs` склеивает `src/*.js` в один `index.html`. Одиночный режим (GitHub Pages) ломать нельзя. Сервер — чистый Node.js без зависимостей (npm install в среде может быть недоступен).

## Уже сделано (этап 1, работает, проверено двумя браузерами в Playwright)
- `server/ws.js` — свой WebSocket RFC6455; `server/sim.js` — загружает общую симуляцию (`01_core, 03_battle, 05_world, 05c_logic`) через `new Function('__SRV', …)`; `server/index.js` — HTTP (`/`, `/health`), мир, бои, встречи, город, голосование, чат. Отладка: `MP_DEBUG=1` даёт `POST /__dbg` (выражение с доступом к `S.G`, `S.sim`, `S.battles`).
- Клиент `src/08_net.js` — «зеркало»: `NET.on` переключает `07_main/06_ui` на отправку команд; снапшоты мира `w` (5 Гц), личные `me` (2 Гц), бой `b` (15 Гц, юниты массивами + события `ev`), клиент строит бой тем же `startBattle(cfg)` и применяет снапшоты (`netSnap`, `netBattleUpdate`).
- Правила: общие часы (`DAY_SEC`, пауза/скорость только по согласию обоих), мир замирает, когда никого нет; поселения безопасны; еда/жалованье не списываются в бою (`busy==='battle'`); дисконнект в бою → `hero.ai=true`, возврат под тем же ником продолжает бой; максимум 2 игрока; `ROOM_CODE` опционален.
- Протокол клиент→сервер: `join, go, goT, goS, enter, leave, hire, gear, tbuy, tsell, equip, unhorse, food, accept, upg, dismiss, attr, enc(a=fight|auto|flee|attack|greet), ack, inp, ord, retreat, prop, vote, chat`.

## Известные хвосты
- Второй игрок на карте рисуется спрайтом, как у первого (палитра героя общая); различается банером и подписью. В `02_art.js` `getHeroSprite` нужно расширить параметром знамени.
- Бой: пауза/скорость/«Меню» не останавливают бой в сети (так и задумано).
- Проверь нагрузку: три одновременных боя по ~150 юнитов на Railway ($5 план).
- Отдых в городе (`rest`) в сети отключён; ожидание на месте (Z) не работает.

## Правила работы
Сервер авторитетен, клиенту не доверяй. После каждого этапа — тест двумя браузерами (Playwright), регрессия одиночки (`index.html` по `file://`), коммит в `main`.
